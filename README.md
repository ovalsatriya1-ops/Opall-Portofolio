# Portfolio Oval Satriya

Website portfolio statis, siap dipublikasikan dengan GitHub Pages.

## Struktur
- `index.html` — halaman utama portfolio

## Deploy ke GitHub Pages
1. Buat repository baru di GitHub.
2. Upload `index.html` ke root repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`.
6. Simpan dan tunggu GitHub Pages menerbitkan website.

Catatan: data edit/admin pada website ini menggunakan `localStorage`, jadi perubahan tersimpan di browser/perangkat yang melakukan edit, bukan ke repository GitHub.
